Analytics Tag Checker

Detect common analytics and tag-manager signatures in pasted HTML.

What it checks

This scan looks for recognizable snippets from common analytics platforms and tag managers so you can spot missing or unexpected tracking code during a template review.

How to use the result

Detection is signature-based rather than network-based. A tag may be loaded dynamically, bundled, or renamed and therefore escape the scan; use your browser's network tools for a complete implementation check.
