HTML Formatter

Make pasted HTML easier to read while inspecting markup structure.

What it checks

Readable markup makes it easier to spot nesting problems, duplicate elements, missing attributes, and accidental fragments copied from another template.

How to use the result

Use formatted output for inspection and debugging. This lightweight formatter is intentionally not a full standards-compliant HTML pretty-printer or code formatter.
