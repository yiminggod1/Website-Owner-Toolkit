SERP Preview

Draft a readable search result title, URL, and description before publishing.

What it checks

A preview makes it easier to judge wording, hierarchy, and truncation risk without pretending to reproduce a search engine's exact rendering.

How to use the result

Keep the page promise clear and specific. Search systems can rewrite titles or snippets, so use this as a writing and consistency tool rather than an exact pixel simulator.
