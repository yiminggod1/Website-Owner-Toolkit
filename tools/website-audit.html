PRACTICAL GUIDE

Website Audit

Start with the page signals that affect discoverability and usability.

What it checks

A first-pass audit groups common page-level signals into one report: title, description, headings, canonical, viewport, images, links, social metadata, structured data, and indexability.

How to use the result

Use it before publishing or after a meaningful template change. A clean report is useful evidence, not a ranking guarantee; deeper crawling, performance testing, and human review still matter.
