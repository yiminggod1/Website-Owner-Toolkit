PRACTICAL GUIDE

DNS Lookup

Query common DNS record types through a browser-accessible DNS-over-HTTPS resolver.

What it checks

DNS records connect names to services such as websites, mail systems, aliases, and nameservers. Looking up the record directly is often faster than guessing from a hosting dashboard.

How to use the result

Use the output to confirm what is publicly published. DNS changes can be cached, and different record types may be served through different names, so interpret the result in context.
