PRACTICAL GUIDE

Favicon Checker

Review favicon, Apple touch icon, and web app manifest references in the HTML head.

What it checks

Small icon declarations affect how a site appears in browser tabs, bookmarks, shortcuts, and some installed experiences.

How to use the result

Confirm that every referenced asset actually exists at the published path and uses an appropriate file type. A manifest is useful but is not a replacement for a browser icon.
