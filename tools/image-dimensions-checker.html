PRACTICAL GUIDE

Image Dimensions Checker

Find images missing width or height attributes and review alt-text coverage.

What it checks

Explicit dimensions give the browser useful layout information before images finish loading, which can reduce layout movement.

How to use the result

Use the flagged list to identify templates that need stable media dimensions. CSS sizing and responsive images still matter, so do not treat the attributes as a complete performance audit.
