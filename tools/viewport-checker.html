Viewport Checker

Check whether pasted HTML declares a useful viewport meta tag.

What it checks

The viewport declaration helps responsive layouts behave as intended on mobile devices.

How to use the result

Use this alongside real responsive testing. A viewport meta tag is necessary for many responsive pages but cannot make a non-responsive layout mobile-friendly by itself.
