Schema Validator

Inspect JSON-LD blocks and catch basic structural problems before publishing structured data.

What it checks

This browser-side validator parses JSON-LD embedded in pasted HTML and surfaces each block, its declared type, and invalid JSON that cannot be parsed.

How to use the result

Treat this as a first validation layer. A syntactically valid JSON-LD block can still use the wrong vocabulary or fail eligibility requirements for a particular search feature.
