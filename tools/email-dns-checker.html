PRACTICAL GUIDE

Email DNS Checker

Inspect MX, SPF, DMARC, and an optional DKIM selector for a domain.

What it checks

Mail-related DNS records help receiving systems understand where mail should be delivered and which authentication mechanisms a domain publishes.

How to use the result

Use the result as a configuration check, then compare it with your mail provider's exact records. A missing DKIM result may simply mean the provider uses a different selector.
